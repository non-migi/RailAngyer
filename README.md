# RailAngyer — レイルアンギャー

サイコロで駅を巡る徒歩すごろくアプリ（身内向け / iOS・SwiftUI）。

「鉄道（Rail）」×「行脚（あんぎゃ）」。
実際に鉄道の駅を歩いて巡り、サイコロの出目だけ駅を進み、着地した駅でチームのミッションを行う。
第1弾は札幌市営地下鉄 南北線（麻生〜真駒内、16駅）。
